Final year project

FAS, Face Recognition Based Attendance Management System

Sole developer, supervised by Mr. Sail Shah
View on GitHub

Problem

Manual, register-based attendance tracking is slow and easy to falsify. Institutions need a way to log attendance that's fast, hands-off, and hard to spoof.

Approach

Built a Flask web application backed by MySQL, using face embeddings for identity matching and a liveness-detection component to resist photo spoofing.

What I built

Owned the full stack: schema design, Flask routes and templates, the recognition pipeline, and a PWA layer with a manifest, icons, and splash screens so it installs like a native app.

Outcome

Carried the project through a full engineering pass and a written, defended thesis, detailed below.

Python Flask dlib face_recognition MySQL / PyMySQL Jinja PWA
Engineering pass. Audited the thesis against the live codebase, corrected an ER diagram with missing columns and stale algorithm descriptions, then cleaned the code from roughly 17,000 to 8,000 lines through safe structural normalization, and refactored inline CSS and JS out of the Flask templates into proper static files.
